0.13.3 adds saved update-source selection and fixes native-pixel aiming and per-display capture on Windows.

- **Update sources**: choose Automatic, AtomGit, GitHub or Gitee in Settings → About and updates. The choice is saved immediately for future checks. Switching clears the previous result; source changes are disabled during downloads.
- **Regional default**: Automatic uses the system region to prefer AtomGit in mainland China and GitHub elsewhere, while comparing stable versions and complete signed packages. A manual choice checks only that source. Startup notices open the update page before downloading so the source can be changed.
- **4K pixel aiming**: at 125%–200% scaling, each arrow press moves by one captured pixel without skipping pixels or changing the other axis. The magnifier continues to sample the original screenshot without selection decorations.
- **Per-display recovery**: retry empty, blank or incorrectly sized SDR grabs using the display's physical position and native resolution; HDR capture failures also try GDI. If a display fails, other available displays remain usable with a notice naming the failed display.

Coordinate and fallback checks cover 4K images, multiple scale factors, negative display origins and portrait regions. The local machine has one display with HDR disabled; these checks do not replace acceptance on the dual-display setup reported in #65. GDI fallback can reduce HDR color accuracy and highlights; output remains standard sRGB.
