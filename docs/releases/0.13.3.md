0.13.3 增加可保存的更新源选择，并修复 Windows 高 DPI 截图的像素定位与逐屏采集问题。

- **更新源**：在“设置 → 关于与更新”中选择自动、AtomGit、GitHub 或 Gitee。选择后立即保存，下次检查继续使用；切换来源会清除旧结果，下载时暂不可切换。
- **国内优先**：自动模式按系统地区判断，中国大陆优先 AtomGit，其他地区优先 GitHub。自动检查仍比较最新正式版本和完整签名程序包；手动选择时只检查所选来源。启动更新提示先打开更新页，方便下载前选择来源。
- **4K 像素定位**：125%～200% 缩放下，方向键每次移动一个原生图像像素，不再跳过像素或让另一条轴偏移。放大镜继续使用原始截图，选区线不会进入放大画面。
- **逐屏采集**：SDR 读到空图、黑帧或尺寸不符时，按该屏幕的物理位置和原生分辨率重读；HDR 采集失败时尝试 GDI 保底。一块屏幕失败时，其他可用屏幕仍可截图，并显示失败提示。

已用 4K 图像、多种缩放、负屏幕坐标和竖屏区域验证坐标与回退路径。本机只有一块显示器且未开启 HDR，不能代替 #65 报告设备的真实双屏验收；请在原场景复测。GDI 保底可能损失 HDR 颜色和高光，输出仍为标准 sRGB。
